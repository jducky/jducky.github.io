# 착시 색 비교 실험실

정적 HTML/CSS/JavaScript로 만든 착시 이미지 비교 도구입니다.  
두 지점의 평균 색을 직접 찍어 비교하고, 같은 회색 배경 위에 다시 보여주거나, 사용자가 직접 자른 이미지 조각을 오버레이로 올려 착시를 설명할 수 있습니다.

## 목적

이 앱은 다음 상황을 빠르게 보여주기 위해 만들었습니다.

- 위쪽과 아래쪽의 얼굴색이 실제로 같은지 확인
- 주변 배경 때문에 다른 색처럼 보이는 착시 설명
- 발표, 수업, 실험용으로 직관적인 비교 화면 제공

## 주요 기능

- 이미지 업로드
  - 파일 선택
  - 클립보드 붙여넣기
  - 드래그 앤 드롭
- 포인트 색 비교
  - A 포인트와 B 포인트를 클릭
  - 평균 색 추출
  - `HEX`, `RGB`, `RGB 거리` 표시
- 중립 배경 비교
  - 두 색을 같은 회색 배경 위에 다시 렌더링
- 주변 어둡게 보기
  - 배경 대비를 줄여 착시 효과를 더 쉽게 설명
- 크롭 오버레이 모드
  - 사용자가 직접 박스를 드래그해 이미지 일부를 잘라냄
  - 잘라낸 조각을 위쪽 이미지 위로 이동해 직접 겹쳐 비교

## 사용 방법

### 1. 이미지 불러오기

다음 중 하나를 사용합니다.

- `이미지 선택`
- 이미지 붙여넣기 `Ctrl+V`
- 이미지 파일 드래그 앤 드롭

### 2. 포인트 모드로 색 비교

기본 상태는 포인트 모드입니다.

- 첫 클릭: `A`
- 두 번째 클릭: `B`
- 이후 클릭: 최근 두 점 기준으로 갱신

오른쪽 패널에서 다음 정보를 확인할 수 있습니다.

- `HEX`
- `RGB`
- `RGB 거리`
- 판정 문구

### 3. 주변 어둡게 모드 사용

상단의 `주변 어둡게` 버튼을 누르면 포인트 주변만 상대적으로 강조됩니다.

설명할 때 유용한 포인트:

- 같은 색인데 주변 밝기 차이 때문에 다르게 보일 수 있음
- 배경 대비를 줄이면 비슷한 색으로 느껴지기 쉬움

### 4. 크롭 오버레이 모드 사용

`크롭 오버레이` 버튼을 누르면 크롭 모드로 바뀝니다.

- 이미지 위를 드래그해서 박스를 지정
- 지정한 영역이 잘린 이미지 조각으로 생성
- 생성된 조각을 드래그해서 원하는 위치로 이동

추천 사용 예:

- 아래 얼굴의 특정 부분을 잘라냄
- 그 조각을 위 얼굴 쪽으로 이동
- 배경이 달라져도 실제 색이 같거나 매우 비슷한지 시각적으로 설명

## 현재 인터랙션 규칙

### 포인트 모드

- 캔버스 좌상단 인디케이터: `포인트 모드`
- 동작: 클릭
- 목적: A/B 색 포인트 선택

### 크롭 모드

- 캔버스 좌상단 인디케이터: `크롭 모드`
- 동작: 드래그
- 목적: 오버레이 조각 생성

## 구현 개요

- 전체 레이아웃
- 이미지 캔버스
- 색 비교 결과 패널
- 모드 버튼과 안내 UI

- RGB 거리 계산
- 포인트/크롭 모드 전환
