# PRD — 직소 링크 퍼즐 (Jigsaw Link Puzzle)

**문서 버전** 1.0  
**작성일** 2026-05-11  
**플랫폼** Android (WebView 기반)  
**배포 채널** Google Play Store

---

## 1. 개요

### 1.1 제품 목표

이미지를 타일로 분할하고, 드래그 앤 드롭으로 원본 이미지를 복원하는 캐주얼 직소 퍼즐 게임이다. 인접한 올바른 타일끼리 자동으로 링크(그룹화)되어 함께 이동하는 것이 핵심 메커니즘이다.

### 1.2 타겟 사용자

- 이동 중 짧은 시간에 즐기는 캐주얼 퍼즐 유저
- 연령 제한 없음 (3세 이상 등급 목표)
- 광고 기반 무료 플레이 선호 사용자

### 1.3 핵심 가치 제안

- 별도 설치 없이 빠른 실행 (앱 용량 5MB 이하 목표)
- 3×3부터 6×6까지 난이도 선택으로 진입 장벽 낮춤
- 링크 메커니즘으로 일반 직소 퍼즐 대비 차별화된 성취감

## 3. 핵심 기능 요구사항

### 3.1 게임 플레이

#### F-01 이미지 타일 분할

- 원본 이미지를 N×M 격자로 균등 분할한다.
- 지원 격자: 3×3, 4×4, 5×5, 6×6
- 분할은 Canvas `drawImage()` 클리핑으로 처리한다.

#### F-02 타일 드래그 앤 드롭

- 단일 손가락 터치로 타일을 드래그한다.
- 드롭 위치에서 가장 가까운 슬롯으로 스냅된다.
- 목표 슬롯에 다른 타일이 있으면 두 타일이 스왑된다.
- 터치 히트박스는 시각 크기보다 10% 크게 설정한다 (6×6 대응).

#### F-03 링크(그룹화) 메커니즘

- 타일이 올바른 위치에 놓이면 인접한 올바른 타일과 자동으로 그룹을 형성한다.
- 그룹 관리는 Union-Find 알고리즘으로 처리한다.
- 그룹에 속한 타일은 함께 이동한다.
- 링크된 타일은 시각적으로 구분 표시(초록 테두리)한다.

#### F-04 완성 판정

- 모든 타일이 올바른 위치에 있으면 완성으로 판정한다.
- 완성 시 애니메이션(페이드 인 배너)과 함께 이동 횟수를 표시한다.
- 완성 후 광고를 노출하고 다음 레벨 또는 재시작 버튼을 제공한다.

#### F-05 힌트

- 힌트 버튼 탭 시 원본 이미지를 1.5초 오버레이로 표시한다.
- 힌트 사용 횟수는 레벨당 3회로 제한한다.
- 힌트 사용 시 클리어 별점에서 1개 차감한다.

### 3.2 레벨 시스템

#### F-06 이미지 팩

- 카테고리: 풍경, 동물, 건축, 예술, 음식 (각 20장 이상)
- 이미지 해상도: 480×480px 이상
- 초기 출시: 총 100레벨 (카테고리별 20레벨)
- 월 1회 신규 팩 추가 (20레벨)

#### F-07 레벨 잠금 및 해제

- 순서대로 클리어해야 다음 레벨이 해제된다.
- 첫 20레벨은 기본 제공 (무료 잠금 해제).
- 이후 레벨은 광고 시청 또는 인앱 구매로 해제한다.

#### F-08 별점 시스템

- 클리어 시 1~3성 부여 기준:
  - 3성: 힌트 0회, 이동 횟수 최적 이내
  - 2성: 힌트 1~2회 또는 이동 초과
  - 1성: 힌트 3회 또는 이동 크게 초과

### 3.3 UI 화면 구성

#### S-01 스플래시 화면

- 앱 아이콘 + 로고 1.5초 노출 후 메인 화면으로 전환.

#### S-02 메인 화면

- 카테고리 선택 그리드
- 최근 플레이 레벨 바로가기
- 설정 버튼, 총 별점 표시

#### S-03 레벨 선택 화면

- 카테고리별 레벨 썸네일 그리드 (3열)
- 클리어 여부, 획득 별점 표시
- 잠금 레벨은 자물쇠 아이콘으로 표시

#### S-04 게임 화면

- 퍼즐 보드 (화면 중앙, 정사각형)
- 상단: 레벨명, 이동 횟수, 연결 수, 힌트 버튼
- 하단: 원본 이미지 썸네일, 난이도 표시

#### S-05 클리어 화면

- 오버레이 모달: 별점 애니메이션, 이동 횟수, 힌트 사용 횟수
- 버튼: 다시 하기, 다음 레벨, 메인으로
- 광고 노출 후 버튼 활성화 (최대 5초 대기)

### 3.4 데이터 저장

#### F-09 로컬 저장

- 레벨별 클리어 여부, 별점, 최소 이동 횟수를 localStorage에 저장한다.
- 앱 재시작 시 이전 진행 상황을 복원한다.

## 5. 비기능 요구사항

### 5.1 성능

- 앱 콜드 스타트: 2초 이내
- 게임 화면 첫 렌더링: 500ms 이내
- 6×6 타일 드래그 프레임: 60fps 유지
- APK 용량: 15MB 이하 (이미지 팩 미포함 시 5MB 이하)

### 5.2 호환성

- 최소 Android 8.0 (API 26)
- 화면 비율: 16:9, 18:9, 19.5:9, 20:9 모두 대응
- 태블릿: 보드 최대 너비 600px로 고정 후 중앙 정렬

### 5.3 오프라인

- 게임 플레이는 네트워크 없이 완전히 동작한다.
- 광고는 네트워크 없을 시 미노출 처리한다.

### 5.4 접근성

- 최소 터치 타겟: 44×44px
- 타일 링크 시 진동 피드백(HapticFeedback) 제공
- 폰트 크기 시스템 설정 연동
