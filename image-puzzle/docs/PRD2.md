# 📄 MVP PRD

**프로젝트명:** Image Puzzle MVP
**목표:** 이미지 퍼즐의 핵심 플레이(조각 이동 + 병합)를 검증하는 모바일 앱

---

# 1. 🎯 제품 목표

## 1.1 목표

* 사용자가 이미지를 조각으로 맞추는 **핵심 퍼즐 경험 구현**
* “타일 병합” 기반 재미 요소 검증
* 최소한의 UI로 빠른 개발 및 테스트

## 1.2 성공 기준

* 퍼즐 1판을 정상적으로 완료 가능
* 앱 재실행 시 이어하기 가능
* 버그 없이 터치 조작 자연스러움

---

# 2. 👤 사용자 시나리오

1. 앱 실행
2. 레벨 선택 (또는 자동 시작)
3. 퍼즐 플레이
4. 조각을 드래그해서 위치 맞춤
5. 맞는 조각끼리 자동 병합
6. 전체 완성 → 완료 화면

---

# 3. 🧩 핵심 기능 정의

## 3.1 퍼즐 생성

| 항목    | 내용         |
| ----- | ---------- |
| 입력    | 이미지 1개     |
| 분할    | 3x3 또는 4x4 |
| 초기 상태 | 랜덤 위치 배치   |
| 회전    | ❌ (MVP 제외) |

---

## 3.2 타일 이동

* 터치 → 드래그 → 이동
* 손을 떼면 위치 고정
* 다른 타일 위로 이동 가능

---

## 3.3 스냅(정답 판정)

* 조건:

  * 정답 위치 근처 (예: ±20px)
* 결과:

  * 자동으로 정확한 위치에 맞춤

---

## 3.4 타일 병합 (핵심 기능 ⭐)

### 동작

* 인접 타일이 둘 다 정답 위치일 경우:
  → 하나의 그룹으로 합쳐짐

### 병합 이후

* 같이 이동
* 같이 드래그됨

### 구현 개념

```text
Tile → Group 구조
단일 타일 → 그룹 생성
병합 시 그룹 merge
```

---

## 3.5 완료 판정

* 모든 타일이 정답 위치
  → 완료

### 완료 시

* 메시지 표시 (“완료!”)
* 다음 레벨 버튼

---

## 3.6 저장 / 이어하기

| 항목     | 내용                         |
| ------ | -------------------------- |
| 저장 시점  | 앱 종료 시 자동                  |
| 저장 데이터 | 타일 위치 + 그룹 상태              |
| 저장 방식  | 로컬 저장 (PlayerPrefs / JSON) |

---

# 4. 🖥️ UI 구성

## 4.1 화면 구조

### 1) 시작 화면 (간단)

* “시작하기” 버튼

### 2) 퍼즐 화면 (핵심)

구성:

* 퍼즐 영역 (중앙)
* 상단:

  * 뒤로가기
* 하단:

  * 힌트 버튼 (옵션)

---

## 4.2 힌트 기능 (선택)

* 버튼 클릭 시:

  * 원본 이미지 2초 표시

---

## 4.3 완료 화면

* 텍스트: “완료!”
* 버튼:

  * 다시하기
  * 다음 이미지

---

# 5. 🏗️ 시스템 설계

## 5.1 데이터 구조

### Tile

```json
{
  "id": 1,
  "correct_x": 0,
  "correct_y": 0,
  "current_x": 120,
  "current_y": 300,
  "group_id": 2
}
```

### Group

```json
{
  "group_id": 2,
  "tile_ids": [1,2,3]
}
```

---

## 5.2 퍼즐 상태 저장

```json
{
  "level": 1,
  "tiles": [...],
  "groups": [...]
}
```
